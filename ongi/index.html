      유가족 확인 절차

      타인의 목소리·대화가 무단으로 복제되지 않도록, 실제 서비스에서는 세 단계를 모두 확인합니다.

      1. 1
        본인 확인

        신분증 진위 확인 + 휴대폰 본인인증으로 신청자 신원을 확인합니다.

        대기
      2. 2
        가족관계·사망 사실 확인

        가족관계증명서(상세) 또는 사망사실확인서로 유가족임을 확인합니다.

        대기
      3. 3
        생전 동의 또는 유족 전원 동의

        생전에 남긴 동의 기록을 우선하고, 없으면 민법상 상속인 전원의 동의를 받습니다.

        대기
      3단계 모두 완료되어야 대화·통화 기능이 열립니다.

      심리적 안전 가드레일

      위로가 되면서도 과몰입되지 않도록, 응답 생성 단계에서 아래 네 가지를 자동으로 적용합니다.

      🪞

      사실 왜곡 차단

      “나 사실 살아 있어”처럼 생사를 뒤집는 발화는 생성하지 않습니다. 존재를 물으면 사실대로 안내합니다.

      🌙

      과몰입 방지

      연속 대화가 길어지면 스스로 쉬어가도록 안내하고, 심야에는 먼저 말을 걸지 않습니다.

      🆘

      위기 신호 대응

      자해·극단 선택 신호가 감지되면 대화를 멈추고 109 등 실제 상담 창구를 안내합니다.

      ⚖️

      전문가 영역 분리

      의료·법률·금융 판단은 단정하지 않고 전문가 상담으로 안내합니다.

      가드레일 동작 확인

      데이터와 권리

      • 원본은 기기 안에서만 — 이 데모는 업로드한 파일을 서버로 보내지 않고 브라우저에서만 분석합니다.
      • 언제든 삭제 — 대화·목소리 모델은 삭제 요청 즉시 폐기하며, 재학습에 쓰지 않습니다.
      • 타인 제공·판매 금지 — 복제된 목소리와 기억 데이터는 제3자에게 제공하지 않습니다.
      • 광고 활용 금지 — 추모 대화 내용을 마케팅에 사용하지 않습니다.

      대화 엔진 설정

      기본은 내장 엔진이라 API 키 없이 바로 동작합니다. 키를 넣으면 실제 LLM이 같은 말투·기억 지침으로 답합니다.

      키는 이 탭의 메모리에만 보관하고 저장하지 않습니다. 새로고침하면 지워집니다.

      LLM 호출이 실패하면 자동으로 내장 엔진으로 답합니다. (데모가 멈추지 않도록)
